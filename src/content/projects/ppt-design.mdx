## 背景

创建演示文稿是技术人员日常工作的一部分，但现有工具要么过于手动（PowerPoint），要么输出不可编辑（HTML 幻灯片导出）。

## 技术架构

PPT Design 作为 Codex 插件运行，提供三层输出：

1. **HTML 演示**: 动态、支持动画、适合在线展示
2. **PPTX 导出**: 真正可编辑的 PowerPoint 文件
3. **设计模板**: 可复用的视觉样式

## 关键特性

- 从项目文档自动生成演示结构
- 支持代码块、架构图、流程图等技术内容
- 商业级视觉设计模板
- 导出为原生 PPTX 格式，完全可编辑

## 成果

- 支持 Codex 平台
- 多套设计模板
- 自动化演示生成流程

## Problem

Presentation work often forces a choice between manual editing in PowerPoint and dynamic HTML output that cannot be edited as native slides. PPT Design combines content analysis, visual direction, HTML authoring, and editable PPTX delivery in one Codex plugin.

## Structure

Three bundled skills divide the work: `frontend-slides` handles presentation engineering and motion, `baoyu-design` develops the narrative and design system, and `html-ppt` provides reusable themes, layouts, and the presentation runtime.

## Outputs

- Animated, navigable HTML presentations
- Native, editable PowerPoint files
- Reusable themes and layout patterns
- Technical content including code, diagrams, and process flows

## Status

The project remains active, but it is no longer the primary focus of this portfolio. It stays here as a design-automation tool and an example of multi-skill delivery.
